# 15. Тест-чеклісти (після кожної збірки)

> Мінімальний прогін ~15 хв. Повний — при змінах відповідної підсистеми.

## Старт/базове
- [ ] Холодний старт без crash-екрана; preloader → home.
- [ ] Зміна мови й теми на льоту (заголовки, drawer, модалки).
- [ ] Drawer: «Нещодавні» оновлюються при КОЖНОМУ відкритті (створення/
      видалення проекту з home і зі списків, порядок після відкриття проекту).

## Проекти
- [ ] Створити → видалити → створити з ТИМ САМИМ іменем (не падає).
- [ ] Дубль активного імені → локалізований снекбар, без краша.
- [ ] Видалення проекту зносить документи (рядки+теку) і призначення слотів.

## Гайдук: документи
- [ ] Мультивибір 3–5 файлів: без чорного екрана; модалка на екрані зі
      списком; лічильник = списку; бейдж з цифрою.
- [ ] Скасування пікера — один «назад» (плюс хіба системне згортання).
- [ ] Подвійний швидкий тап «Додати» — другий пікер не стартує.
- [ ] Файл >1 МБ тексту → звіт «пропущено: перевищує ліміт».
- [ ] 6-й файл → пропущено; кнопка неактивна на 5/5.
- [ ] Однойменний → «замінено», без дубля.
- [ ] Великий файл: снекбар «проіндексовано N/N»; питання по вмісту →
      відповідь з фрагментів; перелік файлів модель бачить завжди.
- [ ] Вайп: бейдж гаснe, індекс scope порожній, тека Gaiduk чиста.
- [ ] Перезаход на екран: лічильники/бейдж збігаються (дедуп).

## Гайдук: інше
- [ ] Меню ⋮: «Експорти чатів» відкриває діалог (тайтл чистий, 95%,
      без розмірів); скачування → Download/Molfar_Gaiduk; видалення.
- [ ] Експорт .txt зʼявляється в діалозі одразу.
- [ ] Шрифт бульбашок 16sp; глобус не перекритий бейджем.
- [ ] Ролі: застосувати/скинути; вибір переживає перезапуск.

## Пул проекту (картка проекту)
- [ ] Мультивибір з MIME-фільтром; воркер (без фризу на великому PDF).
- [ ] Лічильник «N/20 · X/32 МБ»; >1.5 МБ тексту → звіт-діалог з причиною.
- [ ] Заміна однойменного; авто-снекбар «проіндексовано N/N».
- [ ] Видалення файлу пулу знімає його зі слотів і з індексу.

## Нарада
- [ ] Слот приймає до 5 документів (шостий не дається).
- [ ] Раунд: малий док слота цитується повністю; великий — учасник
      відповідає з фрагментів за питанням; перелік файлів у контексті.
- [ ] Черга: парсинг, редагування, адресний раунд 2, фінальний синтез.
- [ ] Секретар: питання по документах; «розкажи про всі документи»
      (огляди); протокол → Exports + Download.
- [ ] Вихід з екрана посеред раунду → повернення: нових крашів нема,
      можна слати знову.
- [ ] Стара нарада зі старими документами: перший раунд доіндексовує сам.

## Памʼять
- [ ] Після раунду зʼявляється запис; pinned підтягується в синтез.
- [ ] Пошук памʼяті кирилицею незалежно від регістру.
