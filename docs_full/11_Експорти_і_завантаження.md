# 11. Експорти і завантаження

> Актуально: 2026-07.

## Сховища
- **Внутрішні експорти**: `Molfar_System/Exports/` — Гайдук (.txt);
  проектні експорти/протоколи — у теках проектів. Джерело теки Гайдука —
  `pop_ai._exports_dir()` (app.exports_dir з creator, fallback cwd/Exports):
  ЗАПИС і ДІАЛОГ дивляться в одну теку через цей хелпер.
- **Назовні (видимі користувачу)**: системна тека Download через
  `modules/downloads.save_to_downloads(src_path, display_name, subfolder)
  -> (ok, dest|err)`. API 29+ — MediaStore.Downloads; API 24–28 —
  legacy-шлях; desktop — ~/Downloads.
- Підпапки Download: Гайдук → `Molfar_Gaiduk`; таби → `Molfar_s-<sess>` / `Molfar`.

## Діалог «Експорти чатів» (Гайдук, меню ⋮)
Пункт chat_menu_exports (замінив мертвий «Експорт в .pdf»). Вікно 95%×90%,
auto_dismiss=False, шапка+хрестик; список файлів Exports найновіші зверху,
імена shorten center, БЕЗ розміру. Тап по імені → підтвердження
(info_dl_export_q) → скачування у фоні + Clock → info_saved/info_save_err;
кошик → info_del_q → видалення + оновлення списку. Порожньо —
info_artifacts_empty. Реюз ключів табів; новий ключ лише chat_menu_exports.

## Експорт .txt Гайдука
`_export_txt` → воркер: кандидати тек від `_exports_dir()` (дедуп) →
файл gaiduck_YYYY-MM-DD_HH-MM-SS.txt → снекбар. Далі файл доступний
у діалозі експортів.

## Таби (InfoTab)
Блоки артефактів: список файлів проекту → тап → підтвердження →
downloads.save_to_downloads у фоні → тост; той самий патерн, з якого
скопійований діалог Гайдука. У меню ⋮ табів досі живе плейсхолдер
export_pdf ([[16_Беклог]]).
