# 09. Документи: три контури лімітів

> Актуально: 2026-07. ЄДИНЕ джерело правди лімітів — `modules/doc_parser.py`.

## Ліміти (критерій СКРІЗЬ — байти ВИТЯГНУТОГО тексту UTF-8)
| Контур | Файли | На файл | Разом | Константи |
|---|---|---|---|---|
| Гайдук (сесія) | 5 | 1 МБ | 5.5 МБ | HAIDUK_MAX_DOCS / _MAX_DOC_BYTES / _MAX_TOTAL_BYTES |
| Пул проекту | 20 | 1.5 МБ | 32 МБ | PROJ_MAX_DOCS / _MAX_FILE_BYTES / _MAX_TOTAL_BYTES |
| Слот наради | 5 (з пулу) | — | backstop 400000 симв. | SLOT_MAX_DOCS / SLOT_DOC_TOTAL_LIMIT |

Спільні пороги гібриду: FULLTEXT_BYTES=50КБ (файл повністю),
FULLTEXT_TOTAL_BYTES=120КБ (бюджет повних текстів на запит).
Формати: SUPPORTED_EXTS = .txt .md .docx .pdf .odt; SUPPORTED_MIMES —
для EXTRA_MIME_TYPES пікера (фільтр дорадчий, розширення перевіряється завжди).

## Гібридна подача (Гайдук і слоти — однакова ідея)
1. Явний перелік прикріплених файлів — ЗАВЖДИ (модель ніколи не скаже
   «файлів немає», навіть якщо індекс не готовий).
2. Малі (≤50КБ) — повний текст, доки сумарно ≤120КБ.
3. Великі й малі понад бюджет — ОГЛЯД (перший чанк) + TOP-8 фрагментів
   з knowledge.db за поточним питанням (scope_files = файли контуру).
4. Самолікування: великий файл без жодного чанка → фонова переіндексація.
Реалізації: Гайдук — `pop_ai._documents_system_text(query)`;
слоти — `meeting_docs.build_slot_docs_block(..., query, kb)`
(query = `_last_user_text` екрана; kb = app.archivist_db).

## Додавання файлів — канонічний конвеєр (обидва контури)
SAF-мультипікер (MIME-фільтр, busy-гейт) → копія у ФОНІ (doc_picker) →
Clock → воркер-екстракція (валідація supported/extract/empty/big) →
Clock → фіналізація в Kivy-потоці: ліміти кількості/обсягу →
**replace-семантика** однойменних (`_strip_copy_suffix`: 'name (1).ext'→
'name.ext'; старий індекс геть, os.replace, БД-рядок перезаписується
атомарно) → звіт (чисто → снекбар «Додано N»; інакше діалог
docs_report_* з причиною docs_skip_* по кожному) → фонова індексація
зі снекбаром «проіндексовано N/N».
Атомарність БД: Гайдук — haiduk_doc_add (DELETE+INSERT в транзакції);
пул — INSERT OR REPLACE по UNIQUE(proj,type,filename).

## Кеш подачі слотів (meeting_docs)
`doc_meta(cache, dir, fn)` → {'text': str|None, 'bytes': int}: у RAM живуть
ЛИШЕ малі тексти; великий (1.5МБ) екстрактиться раз для заміру і далі йде
фрагментами. `read_doc_cached` збережений для сумісності (великі — без кешу).

## UI-стандарти діалогів документів
auto_dismiss=False (фантомні дотики при поверненні з SAF); захист від
подвійного відкриття + скидання посилань лише «свого» екземпляра; лічильник
«N/max · X/maxМБ» (ключ docs_counter); обрізка імен shorten_from="center"
(розширення видно); після додавання список ГАРАНТОВАНО на екрані.

## Видалення

слотів у proj_doc_delete). Вайп Гайдука: + clear_project(0,"haiduk") + тека.
