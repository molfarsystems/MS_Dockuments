# 13. Уроки і патерни (hard-won)

> Найцінніший розділ. Формат: симптом → причина → канонічний фікс.
> Кожен пункт коштував реальної збірки/дебагу.

## 1. Java-потік on_activity_result
**Симптом:** після SAF модалка не зʼявляється, бейдж без цифри, список
«застряг», чорний екран 2–3с; дані в БД правильні.
**Причина:** p4a кличе on_activity_result з Android main thread; віджети
з чужого потоку не рендеряться, важке I/O блокує кадр.
**Фікс:** копія/екстракція у фоновому потоці; UI — лише Clock.schedule_once;
jnius.detach() у фінally потоку. Див. [[10_Потоки_і_пікер]].

## 2. Late-binding `e` у Clock-лямбдах
**Симптом:** on_error ніколи не приходить; у Clock-тіку NameError.
**Причина:** Python видаляє змінну `except E as e` в кінці блоку; лямбда
виконується ПІЗНІШЕ.
**Фікс:** `msg = str(e)` ДО планування; `lambda dt: on_error(msg)`.
Було в 7 місцях трьох менеджерів.

## 3. SQLite NOCASE/LOWER — ASCII-only
**Симптом:** «Бюджет» не знаходиться за «бюджет» (пошук памʼяті/знань).
**Причина:** COLLATE NOCASE і LOWER() згортають лише A–Z.
**Фікс:** нормалізована колонка text_norm=casefold (пишеться при вставці,
backfill через Python) + LIKE ... ESCAPE '\' по ній; keywords — casefold.
Дрібніше: %/_ у запиті — wildcard, завжди екранувати.

## 4. UNIQUE-пастка мʼякого видалення
**Симптом:** створення проекту з іменем видаленого → IntegrityError → (краш
через №5).
**Причина:** UNIQUE(project_name) діє і на status='deleted'.
**Фікс:** при видаленні імʼя звільняється суфіксом `~del#id`; backstop
`_free_deleted_name` перед INSERT/UPDATE (лікує старі БД без міграції).

## 5. Snackbar KivyMD 1.2.0 без text=
**Симптом:** TypeError "Properties ['text'] passed to __init__..." — краш
усього застосунку (виняток у Clock-колбеку).
**Фікс:** єдиний `tools/ui_utils.show_snackbar` — лінивий імпорт,
триступеневий fallback (старий Snackbar → MDSnackbar+MDSnackbarText →
MDSnackbar+MDLabel), НІКОЛИ не кидає. Прямі виклики Snackbar заборонені.

## 6. ConfigParser і inline-коментарі
**Симптом:** «Claude/NH пункт меню…» в заголовку діалогу.
**Причина:** без inline_comment_prefixes хвіст `; коментар` — частина значення.
**Фікс:** у lang/*.ini коментарі ЛИШЕ повнорядкові.

## 7. Гонка async delete + async insert
**Симптом:** лічильники брешуть після заміни однойменного файлу.
**Причина:** два воркер-потоки без порядку — delete міг зʼїсти свіжий insert.
**Фікс:** атомарний DELETE+INSERT в одній транзакції (haiduk_doc_add) або
INSERT OR REPLACE по UNIQUE (пул); окремих delete у replace-флоу немає.

## 8. Фантомний дотик після повернення з activity
**Симптом:** модалка auto_dismiss=True гасне при поверненні з SAF.
**Фікс:** робочі діалоги документів/експортів — auto_dismiss=False; після
пікінгу список ГАРАНТОВАНО (пере)відкривається.

## 9. Спільні посилання між екземплярами модалки
**Симптом:** «лічильник 1/5 — список порожній».
**Причина:** запізніле on_dismiss старої модалки обнуляє віджети нової.
**Фікс:** гейт від подвійного відкриття + `_on_*_dismiss(inst)` скидає
посилання лише якщо inst is поточний.

## 10. Guard-и, що ковтають збої мовчки
**Симптом:** «модель не бачить великі файли», без сліду в UI.
**Фікс-принцип:** кожен guard лишає слід (print у logcat) + видима
діагностика цифрами (снекбар «проіндексовано N/N») + самолікування там,
де можливо. Ізолювати кроки (індексація ПЕРЕД оновленням UI).

## 11. Дрібніше, але памʼятати
- `Clock`-лямбди в циклі — захоплювати змінні default-параметром (`fn=fn`).
- Кожен bind(lang.current) вимагає unbind у dismiss.
- Обрізка імен — shorten_from="center" (розширення видно).
- Порожній екран Pydroid ≠ APK: SAF/шляхи різні, дивись [[03_Збірка_і_середовища]].
