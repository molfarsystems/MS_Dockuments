# Molfar System — технічна документація

> Конфіденційно. Для внутрішнього користування розробника.
> Стан кодової бази: **липень 2026** (після пакетів «Гайдук 5/1/5.5» і «Ліміти табів»).

## Навіщо цей пул нотаток
Повернутись до будь-якого етапу через місяці й за годину відновити повний контекст:
що зроблено, чому саме так, які граблі вже пройдені і де зарезервовані точки розширення.

## Конвенції документації
- Один розділ = один файл, перехресні посилання — вікілінками Obsidian.
- Mermaid-діаграми — компактний стандарт (див. шапку [[12_Схеми_процесів]]).
- Після суттєвих змін коду оновлюється відповідний розділ + дата в його шапці.
- Імена файлів/функцій у тексті — точні, з кодової бази; не «по памʼяті».
