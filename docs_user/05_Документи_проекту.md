# 05. Документи проекту

Спільна тека матеріалів наради. Звідси документи роздаються учасникам
і звідси їх читає Секретар.

## Ліміти і формати
До **20 файлів**, до **1.5 МБ тексту** кожен, разом до **32 МБ**.
Формати: txt, md, docx, pdf, odt. Рахується саме текст: наприклад,
pdf-скан без текстового шару не додасться (звіт скаже «порожній або
нечитабельний»).

## Додавання
Картка проекту → Документи → «Додати»:
- системний вибір одразу кількох файлів (непідтримувані формати вже
  відфільтровані);
- лічильник у шапці показує «N/20 · X/32 МБ»;
- по завершенні — короткий підсумок або звіт з причинами пропуску;
- «Документи проіндексовано: N/N» — матеріали підготовлені до пошуку.

## Заміна і видалення
Файл з тим самим імʼям замінює старий (звіт покаже «Замінено»). Кошик
видаляє файл — він одразу зникає і з призначень усіх учасників.
