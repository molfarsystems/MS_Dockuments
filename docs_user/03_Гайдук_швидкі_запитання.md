# 03. Гайдук — швидкі запитання

Одиночний чат для повсякденних питань: без проекту, без учасників —
ви і одна обрана модель.

## Основи
- **Модель**: кнопка з назвою моделі внизу — список усіх моделей ваших
  провайдерів. Платні позначені $ / $$. Вибір запамʼятовується.
- **Веб-пошук**: кнопка-глобус праворуч — модель шукатиме свіжу інформацію
  в інтернеті (працює на моделях, що це підтримують).
- **Роль**: кнопка «+» біля поля вводу → «Спеціалісти» — накладає на чат
  професійну роль (юрист, аналітик тощо). Там же роль можна скинути.

## Документи сесії (скріпка)
Прикріпіть до розмови до **5 файлів** (txt, md, docx, pdf, odt), до **1 МБ
тексту** кожен, разом до **5.5 МБ**:
1. Тап по скріпці → «Додати» → у системному вікні оберіть одразу кілька файлів.
2. Список показує додане; лічильник вгорі — скільки місця використано.
3. Після додавання великих файлів зʼявиться «Індексація документів…», а потім
   «Документи проіндексовано» — тепер модель може шукати по їхньому вмісту.
4. Файл з таким самим імʼям **замінює** попередній. Непідтримувані чи
   завеликі файли будуть перелічені у звіті з причиною.
Бейдж з цифрою на скріпці — скільки файлів прикріплено. Кошик у списку
видаляє файл.

## Питання по документах
Просто питайте: «зроби висновок по звіту», «що сказано про терміни у
договорі?». Малі документи модель бачить повністю, з великих сама дістає
фрагменти, що стосуються питання.
