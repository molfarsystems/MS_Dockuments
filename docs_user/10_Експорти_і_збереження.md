# 10. Експорти і збереження

Все, що ви хочете забрати з застосунку, потрапляє в системну теку
**Download** телефона — далі діліться як завичай.

## Гайдук
Меню ⋮:
- **Експорт в .txt** — зберегти поточну розмову.
- **Експорти чатів** — список усіх збережених експортів: тап по імені →
  файл падає в **Download/Molfar_Gaiduk**; кошик — видалити зі списку.

## Нарада
- Блоки збережених матеріалів на вкладці Інфо: тап по файлу →
  підтвердження → файл у Download (підпапка Molfar…).
- Протокол секретаря зберігається в матеріалах проекту і забирається
  так само.

## Де шукати файли
Системний застосунок «Файли» → Download → підпапки Molfar_Gaiduk /
Molfar… Звідти — пошта, месенджери, хмара.
