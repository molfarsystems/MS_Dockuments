# 11. Налаштування

⚙ на головному екрані.

## Мова
П'ять мов інтерфейсу: українська, англійська, німецька, іспанська,
французька. Перемикається миттєво, без перезапуску.

## Тема
Темна / світла. Застосовується одразу до всього застосунку.

## AI-провайдери
- Ключі API: вставити, **перевірити підключення**, замінити.
- Моделі: список моделей провайдера; можна додати власну за її ID
  (наприклад, нову модель, яку провайдер щойно випустив) або прибрати
  зайві зі списків вибору.
- Позначки вартості: без позначки — безкоштовна, $ — платна,
  $$ — дорожча. Оплата — на боці провайдера за його тарифами.

## FAQ

найчастіші ситуації ([[14_FAQ]] — розширена версія).
