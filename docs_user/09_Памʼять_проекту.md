# 09. Памʼять проекту

Модератор веде довготривалу памʼять наради: факти, ухвалені рішення,
задачі, вподобання. Завдяки їй наступні раунди «памʼятають» попередні —
навіть через тижні.

## Як це працює для вас
- Після кожного раунду суть підсумку зберігається автоматично.
- Перед новим підсумком модератор сам підтягує записи, дотичні до питання.

## Керування
На екрані наради відкрийте перегляд памʼяті:
- список записів з категоріями і важливістю;
- **закріпіть** (pin) критичні речі — закріплене модератор враховує завжди;
- редагуйте або видаляйте неактуальне.

## Порада
Раз на кілька нарад переглядайте памʼять: два-три точні закріплені записи
(бюджет, дедлайн, головне рішення) працюють краще за десятки дрібних.
