# 01. Початок роботи

## Перший запуск
Після встановлення застосунок сам створить свою робочу теку і бази — просто
дочекайтесь головного екрана. Мову і тему можна змінити одразу:
⚙ Налаштування → Мова / Тема ([[11_Налаштування]]).

## Підключення AI-провайдерів (обовʼязково)
Наради працюють на моделях зовнішніх провайдерів. Підтримуються:
- **Google (Gemini)** — ключ на aistudio.google.com (є безкоштовний рівень);
- **NVIDIA NIM** — ключ на build.nvidia.com (безкоштовні моделі);
- **OpenRouter** — ключ на openrouter.ai (багато моделей, частина безкоштовні;
  платні в списку позначені $ / $$).

Кроки:
1. ⚙ Налаштування → **AI-провайдери**.
2. Оберіть провайдера → вставте ключ API → **Перевірити підключення**.
3. За потреби додайте власні моделі провайдера (кнопка керування моделями).

Достатньо одного провайдера; можна підключити всі три і змішувати моделі
в одній нараді — різні учасники на різних моделях.

## Перше знайомство — Гайдук
Найшвидший спосіб відчути застосунок: головний екран → **Гайдук**
(швидкі запитання) → внизу обрати модель → написати питання.
Далі: [[03_Гайдук_швидкі_запитання]].

## Перша нарада за 5 хвилин
1. Створіть проект типу «Нарада» ([[04_Проекти]]).
2. Відкрийте картку проекту → додайте 1–2 документи ([[05_Документи_проекту]]).
3. Налаштуйте 2–3 учасників: модель + роль (+ документи) ([[06_Учасники_і_ролі]]).
4. Відкрийте нараду, поставте питання на вкладці «Інфо» —
   і дивіться [[07_Нарада_раунди_і_черга]].
