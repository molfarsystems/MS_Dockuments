# 04. Проекти

Проект — це «кімната» окремої теми: свої учасники, документи, чати і памʼять.

## Типи
- **Нарада** — основний робочий формат (учасники + модератор + секретар).
- **Конференція** — те саме для більших/довших обговорень.
- **Orduino** — спеціальний тип під профільні задачі.

## Створення
«+» у блоці типу на головному екрані або в списку проектів: назва
(унікальна в межах типу) + короткий опис → «Створити».

## Картка проекту
Тап по проекту відкриває картку: опис, **Документи** ([[05_Документи_проекту]]),
**Учасники** ([[06_Учасники_і_ролі]]), кнопка входу в нараду.

## Редагування і видалення
У списку проектів ⋮ на рядку → «Редагувати» (назва/опис) або «Видалити»
(з підтвердженням). Видалення прибирає проект разом з його документами
і призначеннями учасників — незворотньо. Після видалення назву можна
використати для нового проекту.
