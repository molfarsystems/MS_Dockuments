# 08. Секретар і протокол

## Питання по документах
Вкладка **Секретар** — це «людина з архівом»: відповідає виключно за
матеріалами теки проекту, з посиланням на файли-джерела.
Приклади: «стисло по кожному документу», «де в договорі йдеться про
відповідальність?», «порівняй цифри у звітах».
Якщо тека порожня — секретар чесно скаже, що документів немає.

## Підготовка документів
Нові файли готуються до пошуку автоматично (повідомлення «Документи
проіндексовано»). Для давніх проектів достатньо просто поставити
питання — застосунок допідготує матеріали сам.

## Протокол засідання
Команда секретарю скласти протокол → офіційний документ: тема, склад,
перебіг (підсумки модератора по раундах), рішення, перелік матеріалів.
Протокол зберігається в матеріалах проекту і його можна забрати в
Download ([[10_Експорти_і_збереження]]).

## Веб-джерела
Якщо в нараді вмикався веб-пошук, знайдені сторінки теж стають частиною
«архіву»: секретар цитує їх з позначкою [WEB] і посиланням.
