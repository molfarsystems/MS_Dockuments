# Molfar System — посібник користувача

Ласкаво просимо! Molfar System — це застосунок для проведення **AI-нарад**:
ви ставите питання, кілька AI-учасників з різними «спеціальностями» відповідають
незалежно, модератор зводить їхні думки в підсумок, а секретар веде документи
і складає протокол. Для швидких одиночних питань є окремий чат — **Гайдук**.

## Три речі, які варто знати одразу
1. Застосунку потрібен **ключ хоча б одного AI-провайдера** — без нього чати
   не відповідатимуть. Як отримати — [[01_Початок_роботи]].
2. Всі ваші дані (проекти, чати, документи) зберігаються **локально на
   телефоні**. Назовні йдуть лише запити до обраних вами AI-провайдерів.
3. Видалення — незворотні: очищення Гайдука і видалення проекту стирають
   і повʼязані документи.
